# Third-party libraries and assets

Exact installed versions are recorded in `package-lock.json`. License files remain available in each dependency's package under `node_modules` after `npm ci`.

| Vite / React plugin | Local development and production build | MIT |
| Vitest | Frontend unit/integration test runner | MIT |
| Testing Library | Test accessible user-facing behavior | MIT |
| jsdom | DOM environment for frontend tests | MIT |
